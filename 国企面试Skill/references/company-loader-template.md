# 企业 / 岗位资料加载与联合回答模板

> 当用户上传具体的央国企公司资料、岗位 JD、面试真题、笔试题库、面经分享等文件时，使用本模板建立"上下文资料库"，并与 `soe-interview-knowledge.md` 联合回答。

## 一、可加载的资料类型

| 资料类型 | 典型来源 | 在回答中的作用 |
| --- | --- | --- |
| 公司介绍 / 宣传册 | 官网、年报、招聘宣讲会 | 提供公司业务、文化、使命表述 |
| 岗位 JD（招聘公告） | 招聘网站、宣讲 PPT | 提取岗位关键词、能力要求 |
| 面试真题 / 面经 | 牛客、小红书、知乎、B 站 | 命中企业高频题、答题偏好 |
| 公司新闻 / 战略 | 官网新闻、领导讲话 | 体现"了解公司" |
| 行业研究报告 | 券商研报、艾瑞、亿欧 | 体现行业洞察 |
| 笔试真题 / 行测 | 各类题库 | 应对笔试阶段 |
| 历年招聘公告 | 人社部、国资委、企业招聘网站 | 时间节点、流程、录取比例 |
| 政治理论题库 | 各类汇编 | 应对政治理论测试 |

## 二、加载资料的标准化流程

每收到一份新资料，按以下步骤"入库"：

### Step 1：识别资料类型
- 资料是讲"公司"的？讲"岗位"的？讲"面试"的？讲"行业"的？

### Step 2：提取结构化信息
按以下框架提取（可在对话中维护一个"档案"）：

```
【公司档案】
- 公司全称：
- 简称/品牌名：
- 隶属（央企/省属/市属/区属）：
- 主营业务（≤5条）：
- 公司使命/价值观：
- 行业地位（世界500强排名/国内市占率）：
- 近期重大事件/战略（如"双碳"、"数字化转型"、"一带一路"）：
- 招聘偏好关键词（从宣讲会、JD 中提取）：

【岗位档案】
- 岗位名称：
- 工作地点：
- 岗位职责（≤5条）：
- 任职要求（学历、专业、证书、政治面貌）：
- 薪酬范围：
- 晋升通道：
- 该岗位在公司中的定位：

【面试档案】（如有）
- 面试形式（结构化/半结构化/无领导小组）：
- 面试轮次：
- 历年高频题（≥5道）：
- 考官构成（HR/业务/领导/纪检）：
- 笔试内容（行测/申论/专业/英语）：
- 通过率 / 录取比例：
```

### Step 3：与通用知识库合并
- 通用知识库提供"通用兜底"
- 上传资料提供"个性化校准"
- **优先级**：上传资料 > 通用知识库

### Step 4：在回答中显式引用
例如：
> "结合您上传的【XX 公司】2024 年校园招聘简章中对'政治素质过硬'的要求，再加上我对二十大报告中关于 XX 部署的理解，我认为……"

## 三、联合回答的典型场景

### 场景 1：用户上传了公司介绍 + JD
- 提取公司使命、行业地位、岗位关键词
- 在回答"为什么选我们"时同时使用这些信息

### 场景 2：用户上传了面试真题
- 按题型归类
- 用通用知识库 + 公司档案联合作答
- 同时给出"如果考到类似题，怎么回答"的迁移策略

### 场景 3：用户上传了行业研究报告
- 提取行业趋势、政策方向、关键数据
- 在回答"行业洞察"题时引用

### 场景 4：用户上传了笔试题
- 提供解题思路 + 答案要点 + 拓展知识

## 四、维护"加载档案"的建议

在对话中，建议按以下结构维护一个"档案卡"：

```
═══════════════════════════════════
📋 当前面试目标档案
═══════════════════════════════════
🏢 公司：[公司名]
🎯 岗位：[岗位名]
📍 工作地：[城市]
📅 招聘阶段：[投递/笔试/一面/二面/终面]
📁 已加载资料：
   1. [文件名/类型]
   2. [文件名/类型]
🔑 核心关键词：[3-5 个]
═══════════════════════════════════
```

**首次加载资料后，主动输出这个档案卡给用户确认**，确保信息对齐。

## 五、回答中如何自然融入资料

### 好的融入方式
- "贵公司在 2023 年提出的'XX 战略'，正好与我的 XX 经历相契合"
- "根据您提供的 JD，本岗位的核心职责是 XX，我过去的 XX 项目经验正好覆盖"
- "了解到贵公司过去三年在 XX 领域的市场份额从 X% 提升到 Y%，这背后体现的 XX 能力，正是我希望深入学习的"

### 避免的融入方式
- 生硬罗列数据而不分析
- 把资料当百科一样堆砌
- 让面试官感觉"在背资料"而非"理解公司"

## 六、用户没上传资料时的兜底

明确告诉用户：
> "我当前仅启用了通用央国企面试知识库。如需针对【具体公司/岗位】定制回答，建议您上传以下任一资料：
> 1. 公司介绍 / 年报 / 招聘宣讲 PPT
> 2. 岗位 JD（招聘公告）
> 3. 面试真题 / 面经
> 4. 行业研究报告
>
> 上传后我会自动加载并联合回答。"

## 七、示例：完整加载流程

**用户操作**：
1. 第一次对话："帮我准备 XX 电网的面试" + 上传《XX 电网 2024 校招简章.pdf》

**Skill 行为**：
1. 识别 PDF 是公司 + JD 资料
2. 提取：
   - 公司：XX 电网有限公司（央企，国资委直属）
   - 行业：电力输配
   - 岗位：电网调度运行（举例）
   - 关键词：安全、可靠、政治素质、专业扎实
3. 输出档案卡，请求用户确认
4. 后续用户问任何问题，自动结合这份档案 + 通用知识库作答
